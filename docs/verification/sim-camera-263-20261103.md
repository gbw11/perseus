## 연결안

화면 주소는 그대로 두고 EC2 nginx 에 `/camera/` → `CAMERA_UPSTREAM` 을 추가한다. EC2 는 이미 Tailscale 로 보드 브로커에 닿으므로, 시뮬레이터 PC 를 같은 tailnet 에 두고 `--camera 0.0.0.0:8090` 으로 띄운다. 바꾸는 것은 EC2 `.env` 의 `CAMERA_UPSTREAM` 한 줄 + `docker compose restart nginx`.

`VITE_CAMERA_URL=http://<PC>:8090/...` 직접 지정은 쓰지 않는다: 빌드 시점 값이라 실카메라 전환 때 다시 빌드해야 하고, HTTPS 콘솔에서 http 이미지는 혼합 콘텐츠로 막힌다(같은 PC 의 `127.0.0.1` 만 예외).

제안 블록 (`deploy/nginx/default.conf.template` 443 server, `location /api/` 앞):

```nginx
    # 카메라 (camera-stream-v1). CAMERA_UPSTREAM 으로 시뮬레이터/실카메라를 고른다
    location /camera/ {
        set $camera_upstream ${CAMERA_UPSTREAM};
        proxy_pass $camera_upstream;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_set_header Host $proxy_host;
        proxy_buffering off;
        proxy_cache off;
        proxy_connect_timeout 3s;
        proxy_read_timeout 1h;
        proxy_send_timeout 1h;
    }
```

`compose.yaml` nginx `environment` 에 `CAMERA_UPSTREAM: ${CAMERA_UPSTREAM:-http://127.0.0.1:9}` (정의하지 않으면 템플릿의 `${CAMERA_UPSTREAM}` 이 nginx 변수로 남아 기동 실패), `.env.example` 에 `CAMERA_UPSTREAM=` 설명 한 줄. 로컬 개발(Vite)은 `frontend/apps/{admin-console,vm-screens}/vite.config.ts` 의 `server.proxy` 에 `'/camera': { target: env.VITE_CAMERA_ORIGIN || 'http://127.0.0.1:8090', changeOrigin: true }` 를 더하면 같은 주소로 본다.

## 남은 것

- `deploy/nginx`·`compose.yaml`·`.env` 반영(배포 담당)과 EC2 → 시뮬레이터 PC tailnet 도달 확인.
- 실제 콘솔 화면에서 패널이 움직이는지 브라우저로 확인.
- 패널 문구는 "세 번째 VM AI 감지 영상" 이다. 시뮬레이터 구성에서는 원본 합성 영상이므로 표시 구분이 필요하면 프론트에서 정한다.
