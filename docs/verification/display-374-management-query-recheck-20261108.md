## 시험 방법

1. 평상시 60초: 표시 presentation API를 약 1초마다 한 소비자가 조회.
2. 관리 조회 120초: 같은 소비자를 유지하면서 VM 목록 `GET /api/v1/vms`를 10초마다 총 12회 조회. 한 번에 하나만 요청하고 timeout은 8초로 제한.
3. 중단 후 60초: VM 목록 요청을 멈추고 같은 표시 소비자만 유지.

세 구간 모두 기존 private 공유 파일을 약 0.25초마다 확인하는 동일한 진단 reader가 있다. 파일이 바뀔 때만 JSON을 파싱하고 root/0600/크기/nofollow 조건을 검사한다. 파일을 읽은 뒤 같은 monotonic clock으로 age를 계산하며 3초 기준을 유지한다. 새로운 직접 Xen 조회는 추가하지 않는다. HTTP 상태만 보지 않고 VM별 source 상태와 오래된 VM 상태에서 current 앱을 표시하는지도 기록한다.

이 추가 reader 자체가 일부 부하를 주므로 실제 브라우저·물리 HDMI·휴대폰의 최종 수락 시험으로 쓰지 않는다. 팀원의 다른 워크로드를 중단시키거나 통제한 시험도 아니다.
