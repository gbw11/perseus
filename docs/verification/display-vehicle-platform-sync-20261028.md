## 겹치는 부분의 조정

`git cherry-pick --no-commit 7ae7ffe`에서 겹친 파일은 아래 네 개였다. `ours`/`theirs`로 파일 전체를 선택하거나 이전 브랜치 파일을 통째 복사하지 않았다.

| 파일 | 통합 내용 |
| --- | --- |
| MonitorPage.tsx | 새 차량 레이아웃에 플랫폼 로고·다크 테마·공통 StatusBadge를 유지. 선택 사유와 연결 단절 시 이전 선택 안내도 유지 |
| MonitorPage.test.tsx | 새 화면 수락과 플랫폼의 오래된 앱 오류/실행 상태 억제·선택 사유 검사를 새 레이아웃에 맞춰 함께 검증 |
| monitor.module.css | 차량 화면 배치를 적용하면서 공통 디자인 토큰·브랜드 스타일 유지. 이전 전체/상세 전용 배치는 새 구성으로 대체 |

`decide_vm` 함수는 최신 platform과 AST가 동일함을 확인했다. 백엔드·Agent·앱/펌웨어·Yocto·관리자 웹·공통 UI 패키지·화면 진입 라우터 및 수집기의 config/mqtt/state는 platform 그대로다.

## 재검증

- 새 worktree 전용 의존성을 기존 npm 캐시로 설치했다. 원본 작업 폴더의 node_modules는 변경하지 않았다.
- 새 화면 빌드, 화면·모델 검사 15개, 해당 표시 프론트 ESLint 통과.
- 최신 플랫폼 기준 수집기 전체 검사 101개 통과. 이전 브랜치의 미이식 테스트를 이번 개수에 포함하지 않았다.
- 첨부된 물리 보드 자료는 기존 `7ae7ffe` 작업에서 수행한 시험 이력이다. 이 통합 후 수정본에 새 물리 시험을 수행한 것으로 해석하지 않는다.
- 실제 속도·배터리·미디어·게스트 영상 연결과 두 모니터 동시 출력 등 미완료 범위는 기존 차량 화면 검증 문서대로 유지한다.

새 MR에는 차량 화면 단일 작업과 이 통합 기록만 올린다. platform 브랜치에 직접 푸시하거나 병합하지 않는다.
