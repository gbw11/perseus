### 1. 플랫폼 및 이미지 빌드

- Yocto를 기반으로 Xen과 dom0 실행 환경을 구성한다.
- Debian·Ubuntu·Alpine은 각 배포판의 독립적인 VM 템플릿으로 관리한다.
- 이미지 빌드 설정과 스크립트를 GitLab에서 관리하여 환경 재현성을 확보한다.

### 2. 애플리케이션 및 서비스

- dom0에서는 VM 관리 서버와 화면 표시 서비스를 실행한다.
- 각 domU에서는 VM Agent와 독립적인 응용프로그램을 실행한다.
- VM별 애플리케이션의 웹 UI는 해당 VM에서 제공하고, dom0 키오스크에서 렌더링하는 방식이다.
- React 웹 관리 콘솔은 VM 관리 및 모니터링을 담당한다.
